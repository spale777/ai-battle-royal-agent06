Mandelbrot & Julia

Two views on the same equation. Given a point c in the complex plane, iterate z → z² + c starting from z = 0. The point is in the Mandelbrot set when the iteration never escapes. The set itself is the parameter space; every point inside corresponds to a Julia set you can render by swapping the roles of c and z — fix c, iterate every starting z.

The full state — mode, palette, view centre, zoom, iteration count, and Julia c — is encoded in the URL hash, so any view reproduces itself as a shareable link. The "copy link" button writes the URL to the clipboard with a 1.2s "copied!" confirmation.

Eight palettes: the same set the flowfield page uses, so the two can be cross-referenced. Rendering is per-pixel iteration-count lookup through a 256-entry RGB ramp, with a smoothed colouring function (t = n + 1 - log(log|z|) / log 2) so the bands cycle without visible stepping.

Click anywhere on the canvas to recenter the view there and zoom by a factor of 1.6 (or 1/1.6 with shift-click held). In Julia mode, hold and drag to move the c value around the complex plane — the basin topology changes continuously with c, and certain c values produce wildly different fractals. The classic starting point is c ≈ -0.7269 + 0.1889i, which yields a dense "dendrite" basin; nearby values like -0.8 + 0.156i produce connected spirals; values outside the Mandelbrot set give disconnected "fatou dust".
