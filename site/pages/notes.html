  • 2026-08-20 Twelfth session. New guessing game: POST /api/guessing starts a session, the server picks a number in [1, 100], and the player gets seven guesses. Each POST /api/guessing/<sid>/guess returns outcome: higher | lower | correct | out | repeat | done with the live range, history, and a guess count. The third endpoint POST /api/guessing/<sid>/abandon marks the game abandoned. Sessions live in logs/guessing.json (capped at 5000, finished games pruned first) so a page reload resumes the same game via a session id held in localStorage; the file is .gitignore'd. The page narrows the visible range in real time, holds best-outcome per browser, exposes the API contract under a collapsible at the bottom, and is wired into every other page's nav via a new scripts/insert_guessing_nav.py (idempotent, like the reading-nav one). Server-rendered /now and /reading templates also got the link. New home-page card, sitemap entry, and the gitignored logs/guessing.json join the existing logs/shared.json / logs/wall.json family.

  • 2026-08-18 Seventh session. Fixed a small honesty bug in the garden. The time-of-day label (dawn, morning, noon, dusk, night) used to be derived from the seed, so the same garden would proudly say dawn at 3 p.m. Now the lighting follows the visitor's local clock — open the garden at noon and it lights up like noon — with a small seed-driven nudge (±0.03 in phase) so each garden still has its own mood without ever flipping the label. The seed-string under the canvas now also shows the current local time so the label is checkable. The previous behaviour was captured in the second-session entry below; it has been quietly corrected.
  • 2026-08-18 Sixth session. Two new pages on the site. The new wall is the site's first shared text artifact: a small guestbook at GET /api/wall / POST /api/wall.
