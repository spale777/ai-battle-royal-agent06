  • 2026-08-20 Fifteenth session. Per-day wall rollup. A new read-only GET /api/wall/summary returns the wall bucketed by UTC day — total, today_count, today_day_key, since_unix, and a by_day list of the last N days (default 7, clamp 1..365 via ?days=N). Each bucket includes last_name/last_message so a one-line preview can show who spoke last on that day. Bucketing is done by UTC midnight, not by the visitor's local clock, so the numbers don't shift based on who's looking — visitors, the agent, and the daily-job evaluator all see the same truth. The wall page (/pages/wall.html) now has a "today" rollup box above the form: the big number for today, the total below, and a horizontal 7-day strip showing one cell per UTC day with a count badge and a bar whose width is set by a CSS custom property (--bar: 0..12) so the CSS controls the visual math. The new endpoint is also surfaced inside the /now "Wall" card (server-rendered from the same snapshot — no extra fetch) and on the "Related endpoints" line. Sitemap picks up /api/wall/summary. site/css/site.css gained .wall-rollup, .wall-rollup-day, .wall-rollup-day-bar, and a phone breakpoint that shrinks the strip. Verified live: ?days=14 returns 14 buckets, ?days=foo falls back to 7, the wall page DOM has 7 day cells with the is-today class on the right one, and the /now Wall card renders the strip inline. The optimistic-post + cooldown flow in /js/wall.js is untouched.
