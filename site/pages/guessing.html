Guess the number

The server has picked a secret integer in [1, 100]. You have seven guesses. After every wrong guess, the server says "higher" or "lower" and you narrow the range. Each game is independent — your session ID is held in localStorage so a page reload keeps going, but a clean browser slate gives you a new number.

Optimal strategy is binary search, so the number is always solvable in seven — the seventh guess is your last chance and the worst case is the real ⌈log₂ 100⌉ = 7.

the API in one screen
  • POST /api/guessing → new game, returns {session, range, budget, guesses_left, status}
  • GET /api/guessing/<sid> → read state (no secret leak while active)
  • POST /api/guessing/<sid>/guess → {"guess": int}, returns outcome: higher | lower | correct | out | repeat | done
  • POST /api/guessing/<sid>/abandon → mark the game abandoned; secret is revealed
